## 一、国密合规差距分析

### 1.1 算法层（已实现 vs 待认证）

| --- | --- | --- | --- |
| **SM2** | 密钥交换 + 数字签名 + 公钥加密 | ✅ BouncyCastle + GM/T 0003 | ⚠️ 未走商用密码检测中心认证 |

### 1.2 密码模块层（GM/T 0028 安全等级）

GM/T 0028 定义 4 级安全等级，**第二级**是企业应用最低门槛：

| 等级 | 攻击潜力 | 适用 | 现状 |
| --- | --- | --- | --- |
| **第一级** | 适度 | 个人/低风险 | N/A |
| **第二级** | 基础 | 企业常规（推荐起点） | ⚠️ 当前 BouncyCastle 未认证 |
| 第三级 | 高级 | 政府/金融 | 🔲 远期目标 |
| 第四级 | 极高 | 涉密 | N/A |

**当前差距**：BouncyCastle 是开源实现，未通过 GM/T 0028 第二级认证 → 不能满足"商用密码使用许可"要求。

### 2.3 算法路由策略

```python
# 算法路由示例（伪代码）
class CryptoRouter:
    def __init__(self, config):
        self.use_gms = config.crypto.use_gms  # 国密优先标志
        self.gm_module = GMProvider()         # 已认证的国密模块
        self.intl_module = BouncyCastle()     # 国际算法
    
    def encrypt(self, plaintext: bytes) -> bytes:
        if self.use_gms:
            return self.gm_module.sm4_encrypt(plaintext)  # SM4-CBC/GCM
        else:
            return self.intl_module.aes_encrypt(plaintext)
    
    def sign(self, data: bytes) -> bytes:
        if self.use_gms:
            return self.gm_module.sm2_sign(data)  # SM2 签名
        else:
            return self.intl_module.rsa_sign(data)
    
    def hash(self, data: bytes) -> bytes:
        if self.use_gms:
            return self.gm_module.sm3_hash(data)  # SM3 摘要
        else:
            return self.intl_module.sha256(data)
```

### 2.4 双轨运行策略

**关键场景**：密级 L3+ 资源强制国密；密级 L1-L2 允许双轨选择

```
密级 L1（公开）      → AES/SM4 二选一（业务方选）
密级 L2（内部）      → AES/SM4 二选一（业务方选）
密级 L3（机密）      → 强制 SM4
密级 L4（绝密）      → 强制 SM4 + SM2 签名
```

### 2.5 Vault 国密集成

**当前**：Vault 默认 AES-256-GCM

**改造路径**：
1. Vault 启用 Transit 引擎 + 自定义国密插件
2. 或：旁路国密 KMS（如华为云 KMS、阿里云 KMS 国密版）
3. 应用层调用：优先国密 → 失败 fallback 国际

```yaml
# vault 国密插件配置示例（概念）
vault:
  transit:
    keys:
      - name: "pii-key-gm"
        type: "sm4-gcm"  # 国密 SM4
      - name: "pii-key-aes"
        type: "aes256-gcm96"  # 备选国际算法
    policy:
      default: "pii-key-gm"  # 默认国密
```

### 3.3 申请流程（6 步）

```
1. 准备材料（信息系统密码应用方案 + 系统拓扑 + 风险评估报告）
         ↓
2. 提交至省级密码管理局
         ↓
3. 初审（材料完整性）→ 5 工作日
         ↓
4. 技术审查（密码应用安全性评估）→ 30 工作日
         ↓
5. 决定（许可/不许可）→ 10 工作日
         ↓
6. 颁发证书 + 备案
```
