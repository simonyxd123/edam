| G-12 | PIA | 1 周 |

**预估费用**：30-48 万元（含测评）

### 4.2 W-2 国密算法集成

**集成点**：
- HLS 视频加密：AES-128 → SM4-CBC（密级 L3+ 强制）
- JWT 签名：HMAC-SHA256 → SM3 摘要
- Vault Transit：增加 SM4-GCM 双轨
- 数据库敏感字段加密：AES-256 → SM4
- TLS 通信：国密 TLS（GMT 0024）

**SDK 选型**：
- 首选：三未信安 / 卫士通（商用，性能高）
- 过渡：BouncyCastle（开源，未认证）

### 4.3 W-3 商密使用许可申请

**6 步流程**：
1. 准备材料（信息系统密码应用方案 20-50 页）
2. 提交省级密码管理局
3. 初审（5 工作日）
4. 技术审查（30 工作日）
5. 决定（10 工作日）
6. 颁发证书 + 备案

**总工期**：6 周
**总费用**：110 万元（含 POC + 改造 + 申请 + 测评）

### 4.4 W-6 频域水印生产集成

**POC 决策（已落地）**：视频用 pHash、图片用 DCT

**生产集成**：
1. pHash 指纹库：每视频 30+ 帧指纹
2. 匹配服务：泄露视频上传 → 逐帧 pHash → 库匹配 → 命中用户
3. DCT 水印服务：文档上传 → 嵌入工号 → 加密存储
4. Worker 集成：异步水印嵌入任务（已有 MQ 流水线）

### 4.5 W-14 第三方安全复审

**复审内容**：
1. STRIDE 35 条威胁复审（基于 modify/2026-08-12-威胁建模报告.md）
2. 红蓝对抗（4 类攻击者画像）
3. 白盒 + 黑盒渗透测试
4. 等保差距分析（基于 modify/2026-08-12-等保三级测评准备.md）
5. 代码审计（Java + Python）
6. 整改建议矩阵

**预算**：50-86 万元
**候选乙方**：奇安信 / 绿盟 / 启明星辰
