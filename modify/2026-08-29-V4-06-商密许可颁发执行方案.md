#### 1.3 算法路由层集成

复用 V4-02 POC 阶段的算法路由层抽象，在生产环境切换：

```java
// 算法路由示例（与 V4-02 路线一致）
public class CryptoRouter {
    private final Config config;
    private final SMProvider gmProvider;      // 三未信安 SDK
    private final BouncyCastle bcProvider;    // 备份/过渡

    public byte[] encrypt(byte[] plaintext, String keyId) {
        if (config.crypto().useGm()) {
            return gmProvider.sm4Encrypt(plaintext, keyId);
        }
        return bcProvider.aesEncrypt(plaintext, keyId);
    }
}
```

**切换策略**：
- D7 完成切换：HLS 视频加密（SM4-CBC）+ Vault Transit（SM4-GCM）+ JWT 签名（SM3）
- 双轨灰度：新请求走 SDK，旧请求维持 BouncyCastle 1 周
