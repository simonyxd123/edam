#### 3.1 多帧冗余（基于 POC §6.4.3）

POC 验证单帧指纹在攻击后 0% 命中率；生产必须用多帧冗余：

| --- | --- | --- |

| **指纹长度** | 64 bit | OpenCV DCT 输出 |
| **匹配阈值** | 汉明距离 ≤ 15 | POC §6.5 决策（不是 10）|
| **多帧投票** | ≥ 3 帧匹配视为命中 | POC §6.5 决策 |

#### 3.2 多帧投票算法

```python
def match_phash_fingerprint(target_phash: str, candidate_keys: List[str],
                            max_hamming: int = 15, min_votes: int = 3) -> Optional[str]:
    """
    多帧投票匹配
    - target_phash: 待溯源帧的 pHash（64 bit hex）
    - candidate_keys: 候选指纹的 Redis keys
    - max_hamming: 最大汉明距离阈值（默认 15）
    - min_votes: 最小投票数（默认 3）
    返回：命中的 user_id 或 None
    """
    votes = defaultdict(int)  # user_id -> vote_count
    pipeline = redis_client.pipeline()
    for key in candidate_keys:
        pipeline.get(key)
    phash_list = pipeline.execute()

    for phash_hex in phash_list:
        if phash_hex is None:
            continue
        # 计算汉明距离
        hamming = bin(int(target_phash, 16) ^ int(phash_hex, 16)).count('1')
        if hamming <= max_hamming:
            user_id = extract_user_id_from_key(candidate_keys[i])
            votes[user_id] += 1

    # 多帧投票
    if votes:
        best_user_id = max(votes, key=votes.get)
        if votes[best_user_id] >= min_votes:
            return best_user_id
    return None
```

#### 6.2 告警配置（AlertManager）

```yaml
# alerts/watermark_phash.yml
groups:
  - name: watermark_phash_alerts
    rules:
      - alert: PhashHitRateDrop
        expr: phash_hit_rate_baseline < 0.70
        for: 30m
        labels:
          severity: warning
          team: watermark
        annotations:
          summary: "pHash 基线命中率下降至 {{ $value }}"
          description: "可能由阈值漂移或算法问题引起，需调优"

      - alert: PhashFalsePositiveHigh
        expr: phash_false_positive_rate > 0.05
        for: 1h
        labels:
          severity: critical
          team: watermark
        annotations:
          summary: "pHash 误报率超过 5%"
          description: "立即收紧汉明距离阈值或扩大投票数"

      - alert: RedisClusterMemoryHigh
        expr: redis_cluster_memory_usage > 0.80
        for: 15m
        labels:
          severity: warning
          team: sre
        annotations:
          summary: "Redis Cluster 内存使用率 {{ $value }}%"
          description: "考虑清理过期指纹或扩容"
```

#### 6.3 阈值调优 SOP

| 触发条件 | 调优动作 |
| --- | --- |
| 命中率 < 阈值 5% | 放宽汉明距离（15 → 17）或减少投票数（3 → 2）|
| 误报率 > 5% | 收紧汉明距离（15 → 13）或增加投票数（3 → 5）|
| 比对 P99 > 5s | 优化 Redis pipeline + 增加集群分片 |
| Redis 内存 > 80% | 提前清理过期指纹 + 扩容 |
