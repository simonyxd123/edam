### 阶段 3：性能基准（W2 D8-D10，3 天）

#### 3.1 编写 JMH 基准测试

每家厂商 SDK 集成后，跑同一套 JMH 测试：

```java
// backend/src/test/java/com/example/edam/crypto/benchmark/SM4Benchmark.java
@BenchmarkMode(Mode.Throughput)
@OutputTimeUnit(TimeUnit.SECONDS)
@State(Scope.Benchmark)
@Warmup(iterations = 5, time = 10)
@Measurement(iterations = 10, time = 10)
@Fork(3)
public class SM4Benchmark {

    @Param({"1024", "1048576"})  // 1KB / 1MB
    private int dataSize;

    private byte[] key;
    private byte[] iv;
    private byte[] data;

    @Setup
    public void setup() {
        key = new byte[16];
        iv = new byte[16];
        data = new byte[dataSize];
        new SecureRandom().nextBytes(key);
        new SecureRandom().nextBytes(iv);
        new SecureRandom().nextBytes(data);
    }

    @Benchmark
    public byte[] sm4CbcEncrypt() {
        return SM4Util.encryptCbc(data, key, iv);
    }

    @Benchmark
    public byte[] sm4CbcDecrypt() {
        return SM4Util.decryptCbc(data, key, iv);
    }
}
```

### 阶段 6：集成方案（W2 D12-D13，2 天）

#### 6.1 双轨切换架构

```java
// backend/src/main/java/com/example/edam/crypto/AlgorithmRouter.java
public class AlgorithmRouter {
    // 配置项（application-prod.yml）
    // crypto:
    //   sdk-provider: bouncycastle | srunsec | westone | gearsecure
    //   switch-strategy: instant | dual-write | phased
    //   dual-write-percentage: 0  # 0-100%

    private final String provider;
    private final int dualWritePercentage;

    public byte[] encrypt(byte[] plaintext, Algorithm algo) {
        if ("phased".equals(strategy) && random.nextInt(100) < dualWritePercentage) {
            // 双轨：写两份（BC + 新 SDK）
            byte[] bcResult = encryptWithBC(plaintext, algo);
            byte[] newResult = encryptWithNewSDK(plaintext, algo);
            verifyBothDecryptable(bcResult, newResult, plaintext);  // 验证一致性
            return newResult;  // 切换后只读新 SDK
        }
        return switch (provider) {
            case "bouncycastle" -> encryptWithBC(plaintext, algo);
            case "srunsec", "westone", "gearsecure" -> encryptWithNewSDK(plaintext, algo);
        };
    }
}
```

#### 6.2 切换策略

| 策略 | 说明 | 适用场景 |
| --- | --- | --- |
| **instant** | 立即切换 | 风险低 + 性能要求高 |
| **dual-write** | 双写（写入新 SDK，读取兼容）| 默认推荐 |
| **phased** | 灰度切换（1% → 10% → 50% → 100%）| 风险高 + 数据敏感 |

#### 6.3 数据迁移方案

如厂商 SDK 不兼容 BC 加密数据：

```bash
# 1. 编写数据迁移脚本（offline）
java -jar data-migration-tool.jar \
  --source-db jdbc:mysql://old-host/edam \
  --target-db jdbc:mysql://new-host/edam \
  --algorithm SM4-CBC \
  --batch-size 1000

# 2. 验证脚本（解密比对）
java -jar data-migration-verify.jar \
  --source-db jdbc:mysql://old-host/edam \
  --target-db jdbc:mysql://new-host/edam
```

### 阶段 7：切换灰度（W2 D14，1 天）

#### 7.1 灰度发布

```bash
# dev 环境：dual-write 100%
# staging 环境：phased 1% → 10% → 50% → 100%
# prod 环境：phased 1% → 10% → 50% → 100%（2 周观察期）
```

#### 7.2 监控指标

- **解密失败率**：必须 < 0.01%
- **加解密 QPS 退化**：必须 < 10%
- **内存增量**：必须 < 100MB/Pod
- **启动时间增量**：必须 < 5s

#### 7.3 回滚预案

```bash
# 紧急回滚（30s 内）

  CRYPTO_SDK_PROVIDER=bouncycastle \
  CRYPTO_SWITCH_STRATEGY=instant

kubectl rollout status deployment/edam-backend

# 验证回滚成功
```
