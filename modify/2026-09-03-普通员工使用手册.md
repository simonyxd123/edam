# EDAM 普通员工使用手册（v3.2）

> 适用对象：已分配 `employee` / `dept_manager` / `auditor` 角色的 EDAM 用户  
> 文档版本：v3.2 / 2026-09-03  
> 配套：管理员使用手册

## 1. 系统简介

EDAM（Enterprise Digital Asset Management）= 企业数字资产防泄密系统。

你作为普通员工，登录后能做的核心 4 件事：
1. **查看** 别人上传的视频/文档（受密级和部门权限限制）
2. **上传** 自己的工作视频/文档
3. **预览** 文档（PDF 自动加水印，记录"何时何 IP 看了什么"）
4. **看自己的审计记录**（谁看了你的资产）

你的水印会随你登录身份变化（看的人不同，水印里的人名不同）。

## 2. 登录

### 2.1 访问入口

- 测试环境：`http://192.168.10.2:5173/`（Vite dev server）
- 正式环境：`http://<你的EDAM域名>/`

### 2.2 登录步骤

1. 打开首页 → 自动跳 `/login`
2. 输入：
   - **工号**（如 `E000001`）  
   - **密码**（首次登录 admin 默认 `admin123`，登录后必须修改）
3. 勾选「记住账号」→ 下次自动填工号（不保存密码，安全）
4. 点「登录」

> **会话超时**：10 分钟无操作后 token 过期，刷页面自动跳回 /login。

### 2.3 登录失败常见原因

| 提示 | 原因 | 解决 |
|---|---|---|
| 工号或密码错误 | 密码错 / 工号输错 | 重输 / 找回密码 |
| 账号已锁定 | 连续 5 次密码错 | 30 分钟后自动解锁；或找管理员重置 |
| 账号已禁用 | status=2 | 联系管理员 |

## 3. 界面导览

登录后看到左侧菜单栏（**只显示你有权限的菜单**）：

```
仪表板 / 视频 / 文档 / 水印溯源 / 设置
```

普通员工通常看到以上 5 个菜单。管理员额外有「外发审批 / 审计日志 / 角色权限」。

## 4. 仪表板（首页）

打开后默认进入。显示 4 个统计卡 + 系统欢迎语。

| 卡片 | 含义 |
|---|---|
| 视频总数 | 系统现存视频数（含所有密级） |
| 文档总数 | 系统现存文档数 |
| 待审批 | 等待审批的外发申请数（**普通员工通常为 0**，看不到申请流程） |
| 今日登录 | 今天所有用户登录累计次数 |

## 5. 视频管理

### 5.1 查看视频列表

左侧「视频」→ 看到所有你能访问的视频（按密级 / 部门过滤）。

| 列 | 说明 |
|---|---|
| ID | 视频 ID |
| 标题 | 视频名称 |
| 类型 | L1 公开 / L2 内部 / L3 机密 / L4 绝密 |
| 时长 | 视频秒数（来自 ffprobe，导入后 30 秒内生成） |
| 大小 | 字节数（MB） |
| 状态 | pending（待转码）/ processing（转码中）/ ready（可播）/ failed（失败） |

### 5.2 上传视频

1. 列表右上「+ 上传视频」按钮
2. 弹窗：
   - 选择本地视频（mp4 / mov / mkv，最大 2GB）
   - 选密级（L1 公开 / L2 内部 / L3 机密 / L4 绝密）
   - 默认标题 = 文件名（可改）
3. 点「开始上传」

上传过程：
- **进度条**显示百分比（基于 axios onUploadProgress）
- 后端插入 video_resource（status=pending）
- MQ 推 `video.preprocess` 消息
- Worker 异步跑 FFmpeg 转 HLS + 提取帧指纹 + 烧水印
- 转码完成 → 前端轮询 → 弹"可播放"

> **L3 机密 / L4 绝密视频自动烧水印**（员工工号 + 时间戳，右下角）

### 5.3 播放视频

1. 列表点「播放」→ 跳 `/videos/{id}`
2. 自动 HLS 播放（mp4 切片成 .ts 段 + AES 加密）
3. **水印叠加**：屏幕右下角小字 "EDAM {工号} 视频 {id} {时间戳}"
4. 播放期间记 `preview` 审计日志（IP / UA / 视频 ID）

## 6. 文档管理

### 6.1 查看文档列表

左侧「文档」→ 表格：标题 / 类型 / 大小 / 水印状态 / 预览状态 / 上传时间。

| 类型 code | 含义 |
|---|---|
| `docx` | Word |
| `xlsx` | Excel |
| `pptx` | PowerPoint |
| `pdf` | PDF |
| `image` | PNG / JPG / GIF |

### 6.2 上传文档

1. 「+ 上传文档」按钮
2. 弹窗选文件 + 选密级 + 「是否启用水印」（默认开）
3. 点「开始上传」

### 6.3 预览文档（重点功能）

1. 文档行 → 「预览」按钮
2. 弹窗：
   - **PDF**：iframe 内嵌，浏览器原生渲染
   - **Office**（docx/xlsx/pptx）：弹提示 + 「下载 / 新窗口打开」按钮（前端无法直接渲染 Office，需客户端软件打开）
   - **图片**：iframe 内嵌
3. **服务端动态水印**：无论 PDF 还是图，下载前都会烧入**当前预览者**的工号 + 时间戳
   - 截图下载传播 → 水印随预览者走 → 事后审计能追责
4. 预览时记 `preview` 审计日志

## 7. 水印溯源

左侧「水印溯源」→ 看到所有水印记录（你作为创建者 / 预览者）。

| 列 | 含义 |
|---|---|
| 资源 | 视频 N / 文档 M |
| 烧入时间 | 当时跑 FFmpeg / PDFBox 的时间 |
| 水印内容 | "EDAM {工号} 视频/文档 {id} {ts}" |

这页用于事后追溯："这份资料是 X 月 X 日 Y 员工 Z IP 看的"。

## 8. 设置

左侧「设置」→ 3 个 Tab：

### 8.1 个人信息
查看工号 / 姓名 / 邮箱 / 当前角色。**只读**，要改联系管理员。

### 8.2 密码修改
- 输入旧密码 + 新密码 + 确认密码
- 后端校验旧密码 + bcrypt 编码新密码 + 更新 `must_change_password=0`

### 8.3 系统配置（**仅 dept_manager / admin 可见**）
- L3 强制 MFA / 会话超时 / 文件大小上限 等
- 普通员工看不到这个 Tab

## 9. 快捷操作 / 高频问题

### Q: 上传视频 / 文档后多久能用？
- 上传成功 → 后端返 202（pending）
- Worker 跑 FFmpeg（30 秒 ~ 3 分钟，看视频长度）
- 完成后**前端自动弹"可播放"通知**
- 列表状态从 `pending` → `processing` → `ready`

### Q: 我没看到"外发审批"菜单？
- 只有 `dept_manager` 角色有审批权，普通员工看不到

### Q: 误删除文档 / 视频能找回吗？
- 软删除（status=2 禁用）→ 不物理删除
- 联系管理员用 `sys_user_role` 直接改 `status=1` 恢复（仅 admin）

### Q: 能不能下载原始文件？
- **PDF / 图片** 预览会烧水印，下载的是带水印版
- **视频** 走 HLS 流，不能直接下载（防截屏传播）
- 原始文件**只能**通过管理员审批后外发（外发审批模块）

## 10. 安全提示（请仔细阅读）

1. **不要** 在浏览器保存密码（EDAM 不提供"记住密码"功能，仅记账号）
2. **不要** 在公共电脑登录
3. **不要** 分享工号 / 密码
4. **不要** 试图绕过水印（截图传播可被审计追责）
5. **及时** 退出登录（右上角用户菜单 → 退出）
6. **异常** 看到敏感资料立即报 IT

## 11. 常见问题

### Q1: 登录后看不到菜单？
→ 检查你的角色（右上角用户菜单 → 我的角色）。普通员工应有 `employee` 角色。

### Q2: 上传文件 413 错误？
→ 文件超过 2GB（视频）或 50MB（文档）。压缩后再传。

### Q3: 视频转码失败？
→ 通常是源文件损坏或编码特殊。找管理员手工转码后用 FFmpeg push 走内部接口。

### Q4: 工号 / 密码忘了？
→ 联系管理员重置。**不要** 在聊天里发密码。

### Q5: 移动端能用吗？
→ 当前 PC only。响应式布局适配小屏，但功能按桌面设计。
