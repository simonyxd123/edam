## 二、各改进项详细说明

### 2.1 V-1 后端 Controller 补全（37 端点）

**来源**：`modify/controller-coverage.md`

**优先级**：P0（生产部署前必完成）

**缺失分布**：
- P0 核心（7 端点）：auth/health/videos/documents/playback
- P1 常用（10 端点）：permissions/distribution/audit/users/watermarks
- P2 扩展（20 端点）：admin/tags/notifications/webhooks/search/preview

**实施策略**：
- 每个 Controller 必须包含单元测试 + 集成测试
- Swagger 注解（@Operation、@Parameter）与 OpenAPI tag 一致
- 完成后用 `scripts/check_controller_coverage.py` 自动验证 100% 覆盖

### 2.2 V-2 数据库迁移规范落地

**来源**：v3.1 修复版 P0-5

**实施步骤**：
1. Spring Boot 集成 Flyway（默认）
2. 创建 `src/main/resources/db/migration/` 目录
3. 命名规范：`V<YYYYMMDD>__<description>.sql`
4. 灰度发布：大表 ALTER 用 gh-ost
5. 回滚脚本：`U<version>__<description>.sql`（Flyway repair）

**验收**：CI 中加入 `flyway validate`，失败则拒绝合并

### 2.3 V-3 登录限流实施

**来源**：v3.1 P0-4

**实施步骤**：
1. Redis + Lua 脚本实现令牌桶限流
2. Key：`ratelimit:login:ip:<ip>`、`ratelimit:login:emp:<emp_no>`
3. 阈值：IP 5/min、工号 3/min
4. 超阈值响应头 `X-Captcha-Required: true`（前端展示验证码）
5. 连续 5 次密码错误 → 账号锁定 30 分钟

### 2.4 V-4 cursor-based 分页

**优势**：
- 性能稳定（O(log n)，不随页数增大变慢）
- 支持实时数据（新增/删除不影响翻页）
- 适合前端长列表

**实施**：
- 新增 `?cursor=<base64>&limit=20` 参数
- 返回 `next_cursor`、`has_more`
- 保留旧 `page`+`page_size` 参数（向后兼容 6 个月）
- 6 个月后 API 标记 deprecated（响应头 Sunset）

### 2.5 V-5 sys_role 软删除

**实施步骤**：
1. sys_role 表添加 `deleted_at DATETIME(3) NULL`
2. 实体类加 `@TableLogic`
3. FK 关联 `ON DELETE RESTRICT`
4. 删除 SQL 改为 `UPDATE sys_role SET deleted_at = NOW() WHERE id = ?`
5. 保留硬删除通道（合规审计需求时）

### 2.6 V-6 Webhook 重试机制

**当前状态**：webhook 表已定义，重试机制缺失

**实施**：
```java
// 重试策略：指数退避
public RetryPolicy exponentialBackoff() {
    return RetryPolicy.builder()
        .maxAttempts(5)
        .backoffOptions(50, 2.0)  // 初始 50ms，倍数 2
        .build();
}

// 死信队列
@Bean
public Queue webhookDeadLetter() {
    return QueueBuilder.durable("webhook.dlq").build();
}
```

**重试间隔**：1min → 5min → 30min → 2h → 12h
**失败 N 次**：进入死信队列 + 告警
**WebhookDelivery 表**：记录每次投递详情（已有 schema）

### 2.7 V-7 ES 索引策略

**当前**：search API 已定义但 ES 索引策略未细化

**关键决策**：
- 视频/文档统一存 `edam_resources` 索引
- Mapping 设计：
  - `id` (keyword)
  - `title` (text + ik_max_word 分词)
  - `tags` (keyword array)
  - `asr_text` (text, 仅视频)
  - `classification_lv` (keyword)
  - `created_at` (date)
- 索引分片：3 分片 + 2 副本
- 别名：`edam_resources_v1` → 切换索引时用 `edam_resources_v2` 双写

### 2.8 V-8 sys_session 表添加

**当前问题**：方案书第十三章 §13.1 提到"sys_session"但 database_schema.md 未定义

**实施方案**：
- 已在 §1.5 节定义（17 张核心表之一）
- 与 OpenAPI 的 `/auth/login` / `/auth/logout` / `/auth/refresh` 对应
- 字段：session_id、refresh_token_hash、user_id、ip、user_agent、expire_at

**验收**：补全 Flyway 迁移脚本

### 2.9 V-9 移动端原生 SDK

**目标**：让第三方 App（企业 IM、邮件客户端）能安全嵌入 EDAM 视频/文档

**SDK 接口**：
```swift
// iOS Swift
EDAMPlayer.shared.playVideo(
    url: "https://api.example.com/api/v1/videos/123",
    token: jwt,
    onWatermarkOverlay: { frame in
        // 用户名 + 时间水印
    }
)
```

**实施**：
- iOS：AVPlayer 包装 + HLS 解密 + Canvas 水印
- Android：ExoPlayer 包装 + HLS 解密 + Canvas 水印
- 集成示例 + Demo App

### 2.10 V-10 OpenAPI 一致性扫描 CI 化

**改进自 V-1**：把 `scripts/check_controller_coverage.py` 集成到 CI

```yaml

    coverage = float(match.group(2))
```
