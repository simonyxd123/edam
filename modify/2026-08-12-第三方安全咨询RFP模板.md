- 编制日期：2026-08-12
- 编制方：EDAM 安全团队
- 目标：邀请第三方安全咨询机构对 EDAM 系统进行实战化威胁建模与红蓝对抗演练
- 关联文档：`modify/2026-08-12-威胁建模报告.md`

---

## 一、项目背景

EDAM（Enterprise Digital Asset Management）是企业内部的全格式数字资产防泄密系统，覆盖视频与文档两类资产。系统已发布 v3.1 版本（51 个 API / 18 张数据表 / 6 层纵深防御）。

为响应等保三级测评与企业安全战略，需要引入第三方安全咨询机构进行实战化威胁建模与红蓝对抗演练，验证现有防御体系的有效性，识别未识覆盖的威胁场景。

---

## 二、项目目标

1. **实战化 STRIDE 复审**：对内部产出的 35 条威胁条目进行复审、补充与修正
2. **红蓝对抗演练**：模拟 4 类攻击者（内部恶意员工/外协/离职员工/外部黑客）
3. **渗透测试**：白盒（提供源码）+ 黑盒（仅提供目标）双视角
4. **等保三级差距分析**：对照 GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》
5. **代码审计**：重点审计 backend（Java 17 + Spring Boot 3.x）与 worker（Python 3.10）

---

## 三、项目范围

### 3.1 包含范围

| 系统 | 技术栈 | 版本 |
| --- | --- | --- |
| 后端 | Java 17 + Spring Boot 3.3 + MyBatis-Plus | backend/ |
| Worker | Python 3.10 + FastAPI + aio-pika | worker/ |
| 前端 | Vue 3 + Vite + Pinia | web/ |
| 数据库 | MySQL 8.0 + Redis Cluster + MinIO + Vault | dev/ + helm/ |
| 部署 | Kubernetes 1.24+ + Helm Chart | k8s/ |

### 3.2 不包含范围

- 第三方商业产品（如 IP-guard、天喻）的安全测试
- 等保测评本身（测评由测评机构执行，本项目输出差距分析）
- 物理安全检查
- 员工社工测试（需 HR 法务另行委托）

## 六、技术要求

### 6.1 乙方资质

| 维度 | 要求 |
| --- | --- |
| 资质证书 | CCRC（原 CNAS）信息安全风险评估资质 + ISO 27001 咨询资质 |
| 行业经验 | ≥ 5 年金融/政府/央企行业安全咨询经验 |
| 团队规模 | 核心团队 ≥ 10 人（项目经理 + STRIDE 专家 + 红队 + 蓝队 + 渗透测试 + 代码审计） |
| 红蓝对抗 | 至少 3 名认证红队成员（OSCP / OSEE / CRTP） |
| 代码审计 | 至少 2 名 Java 安全专家 + 2 名 Python 安全专家 |
| 案例 | 近 3 年内 ≥ 3 个等保三级咨询案例（提供脱敏案例摘要） |

### 6.2 方法论要求

| 模块 | 方法 | 工具 |
| --- | --- | --- |
| STRIDE | Microsoft SDL + STRIDE 2014（Shostack） | Microsoft Threat Modeling Tool 2024 |
| 红蓝对抗 | TIBER-EU + CBEST | Cobalt Strike / Metasploit / 自研 |
| 渗透测试 | OWASP WSTG + PTES | Burp Suite Pro / Nessus |
| 等保差距 | GB/T 22239-2019 | 等保工具箱 |
| 代码审计 | OWASP ASVS + CWE Top 25 | SonarQube + 人工审计 |

### 6.3 保密要求

- 签署三方 NDA（甲方 + 乙方 + 监理）
- 所有交付物标记「机密」，仅限甲方安全团队 + 高管层
- 乙方内部访问受控（项目组成员实名 + 背景调查）
- 离场 7 天内归还所有数据 + 删除本地副本（需提供销毁证明）
