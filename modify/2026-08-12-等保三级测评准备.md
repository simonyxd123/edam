# 等保三级测评准备报告

- 编制日期：2026-08-12
- 编制依据：
 - GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》
 - GB/T 25070-2019《信息安全技术 网络安全等级保护安全设计技术要求》
 - GB/T 28448-2019《信息安全技术 网络安全等级保护测评要求》
- 测评级别：第三级（S3A3G3，**业务信息安全等级 S3 / 系统服务安全等级 A3 / 总体 G3**）
- 系统定级：依据《定级指南》GB/T 22240-2020 → 业务信息 + 系统服务均达到三级
- 关联决策：
 - 方案 B（移除驱动层）→ 终端管控类要求部分降级，需通过前端/制度补强
 - STRIDE 威胁建模 35 条 → 与等保差距项交叉映射

## 四、测评机构 RFP

### 4.1 测评要求

| 项 | 要求 |
| --- | --- |
| 测评级别 | 第三级 |
| 测评范围 | 整个 EDAM 系统（含 web / backend / worker / DB / 中间件） |
| 测评依据 | GB/T 22239-2019 / GB/T 28448-2019 |
| 测评方式 | 访谈 + 文档审查 + 工具测试 + 渗透测试 |
| 测评周期 | 现场测评 5-10 工作日 |
| 输出 | 等保测评报告（含整改建议） |

### 4.2 测评机构资质

- 必须具备公安部第三研究所颁发的**网络安全等级保护测评机构推荐证书**（全国约 200 家）
- 测评师 ≥ 3 名（持证）
- 测评案例：近 3 年 ≥ 3 个等保三级测评
- 行业经验：金融 / 政府 / 央企优先

### 4.3 候选机构（建议 3 家投标）

- 国家信息技术安全研究中心（公益性，权威）
- 中国信息安全测评中心（国家级）
- 各省级测评机构（如等保测评深圳中心、北京测评中心）

### 4.4 测评费用估算（按方案书 §16.4 已调整）

| 项 | 金额（万元） |
| --- | --- |
| 测评费（一次性） | 20-30 |
| 整改咨询（含 1 次安全咨询） | 5-10 |
| 复测费（年度） | 5-8 |
| **合计（首年）** | **30-48** |

**注意**：原方案书 §16.4 节 "¥80,000 等保三级测评"已被 v2.0 评审识别为严重偏低，本报告按市场真实价格校正。

### 4.5 测评 RFP 模板

```yaml
# 测评机构应提交材料
1. 公司资质（测评机构推荐证书复印件）
2. 近 3 年等保三级测评案例（脱敏摘要）
3. 测评师团队简历与证书
4. 测评方案（含时间表 / 工具 / 方法论）
5. 详细报价（按测评项拆分）
6. SLA（报告交付时限 / 整改咨询次数）
7. 保密协议
```
