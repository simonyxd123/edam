### 6.3 V4-03 k6 压测执行与容量规划

**目标**：验证 v3.3 SLO 基线 + 输出容量规划

**SLO 基线**（来自总结报告 6.3）：

- P50 延迟 < 100ms
- P95 延迟 < 200ms
- P99 延迟 < 500ms
- 错误率 < 1%
- 单 Pod QPS ≥ 200

**压测脚本覆盖**：

| 脚本 | 端点 | 流量比例 |
| --- | --- | --- |
| 鉴权 | POST /api/v1/auth/login + /refresh | 20% |
| 视频播放 | GET /api/v1/playback/token + Nginx secure_link | 30% |
| 文档下载 | GET /api/v1/documents/{id}/download | 15% |
| 水印 | POST /api/v1/watermarks/extract | 10% |
| 外发审批 | POST /api/v1/distribution | 5% |
| 搜索 | GET /api/v1/search/videos + /documents | 10% |
| 通知 | GET /api/v1/notifications | 5% |
| 审计 | GET /api/v1/audit/logs | 5% |

**压测档位**：

| 档位 | QPS | 持续时间 | 目标 |
| --- | --- | --- | --- |
| 烟囱 | 50 | 5min | 验证脚本 + 链路 |
| 负载 | 200 | 10min | 验证 SLO 达标 |
| 峰值 | 500 | 10min | 验证弹性 + 告警 |
| 极限 | 1000 | 5min | 找瓶颈 |

**输出**：

- 实测报告（每档 QPS + P50/P95/P99 + 错误率 + 资源使用率）
- 容量基线（单 Pod 推荐 QPS + 推荐副本数）
- 弹性策略（HPA 阈值 + 限流阈值）

**执行**：W1（2026-09-01 ~ 2026-09-08）

### 6.4 V4-11 AI 辅助文档审核（v3.4 创新项）

**目标**：在外发审批流程中插入 AI 审核节点，自动识别敏感信息（合同金额、个人信息、涉密关键词），作为人工审核前的二次过滤

**模型选型**：

| 候选 | 优势 | 劣势 |
| --- | --- | --- |
| Qwen 2.5 72B | 中文好 + 开源 + 可商用 | GPU 成本高 |
| GLM-4 | 中文优秀 + 智谱 API | 需联网 + 数据出境 |
| Llama 3.1 70B | 英文好 + 开源 | 中文弱 |

按"自动选择第一个选项" → 首选 **Qwen 2.5 72B**（中文场景最贴合）

**集成架构**：

```
外发审批请求
   ↓
规则引擎（关键词 + 正则，毫秒级）→ 命中 → 拒
   ↓ 未命中
AI 审核（Qwen 2.5 72B，秒级）    → 命中 → 拒 / 转人工
   ↓ 未命中
人工审批
   ↓
外发
```

**训练数据**：

- 历史外发审批的通过/拒绝样本（脱敏）
- 公开合同模板（合同金额、个人信息字段）
- 行业敏感词库

**风险与缓解**：

- LLM 输出不稳定 → 强制 human-in-the-loop + 阈值告警
- 数据出境风险 → 本地化部署（Qwen 私有化）
- GPU 成本 → 共享 GPU 池 + 弹性扩缩

**工期**：8 周（W17-24，2027-01-15 ~ 2027-03-15）

**预算**：20 万元（GPU 算力 + 算法工程师 + 后端工程师）

**POC 阶段**（W17-19）：

- 数据集准备（5000 样本）
- 模型微调（Qwen + LoRA）
- 红队测试（100 个对抗样本）

**集成阶段**（W20-24）：

- 规则引擎 + AI 引擎双链路
- 审批流程插入
- 监控看板 + 误报率告警
