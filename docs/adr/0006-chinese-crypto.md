# ADR-0006：国密 vs 国际算法

- **状态**：✅ 已接受
- **日期**：2026-08-12

## 上下文

本系统涉及视频/文档/驱动加密、密钥管理、数字签名、消息摘要，需选择密码学算法。

## 评估

### 国际算法（默认）

- **对称加密**：AES-128 / AES-256
- **非对称**：RSA-2048 / ECDSA-P256
- **哈希**：SHA-256 / SHA-512
- **消息认证**：HMAC-SHA256
- ✅ 性能高（硬件加速 AES-NI）
- ✅ 库支持完善（Java BouncyCastle、Python cryptography）
- ❌ 不符合等保三级 + 国密合规要求（涉密行业）

### 国密算法

- **对称加密**：SM4（128-bit 分组）
- **非对称**：SM2（基于 ECC，256-bit）
- **哈希**：SM3（256-bit 输出）
- ✅ 符合《商用密码管理条例》
- ✅ 等保三级要求"采用商用密码"
- ❌ 性能略低（无硬件加速时 SM4 ≈ AES-128 50%）
- ❌ 库支持需要认证（GMSSL、Tongsuo）

## 决策

**国密 + 国际双轨，根据业务场景选择**。

### 场景映射

| 场景 | 算法选择 | 理由 |
| --- | --- | --- |
| 终端驱动加密（Windows） | AES-256 | 硬件加速 + 跨平台 |
| 终端驱动加密（涉密行业） | SM4 | 等保合规 |
| HLS 视频切片 | AES-128 | 行业标准、播放器兼容 |
| 数字签名 | SM2（主）+ ECDSA（备） | 国密合规 |
| 消息摘要 | SM3（主）+ SHA-256（备） | 国密合规 |
| Token 签名 | HMAC-SHA256 | JWT 标准 |
| Vault 密钥派生 | SHA-256 | Vault 默认 |

### 库选型

- **Java**：BouncyCastle（含 SM2/SM3/SM4 实现）+ 国密认证库 GMSSL Java
- **Python**：cryptography（含国密扩展）+ GMSSL Python
- **驱动层**：Windows CNG / macOS CCC / Linux libgcrypt

## 合规路径

1. **使用经国家密码管理局认证的国密算法库**（GMSSL、Tongsuo）
2. **不自行实现密码学算法**（避免引入漏洞）
3. **密钥管理服务（Vault）支持国密**（需采购 Vault Enterprise 或自研包装）
4. **定期密码学合规审计**（年度）

## 后果

- **正向**：满足等保三级 + 涉密行业合规
- **负向**：双轨制增加复杂度；性能略低
- **缓解**：抽象 CryptoProvider 接口，业务层不感知具体算法
