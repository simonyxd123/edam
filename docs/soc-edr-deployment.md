## 一、SOC 态势感知（G-2）

### 1.1 选型

| 候选 | 类型 | 优势 | 劣势 | 推荐度 |
| --- | --- | --- | --- | --- |
| **OSSIM（开源）** | 开源 SIEM | 免费 + 社区 | 部署复杂 | ⭐⭐⭐ |
| **Elastic SIEM** | 开源 + 商业 | 与现有 ELK 集成 | 商业版功能受限 | ⭐⭐⭐⭐ |
| **阿里云云安全中心** | SaaS | 即开即用 | 依赖云 | ⭐⭐⭐⭐ |
| **华为云 HSS** | SaaS | 国内合规 | 依赖云 | ⭐⭐⭐⭐ |
| **奇安信 NGSOC** | 商业 | 国内合规 | 商业授权 50-100 万/年 | ⭐⭐⭐⭐⭐ |

**推荐**：奇安信 NGSOC（等保合规 + 国内最佳实践）

### 1.2 部署架构

```
EDAM 各服务（backend / worker / web / k8s）
           ↓ Filebeat / Fluentd
   ELK 集中日志（v3.3 W-1 G-3）
           ↓ 日志转发
   奇安信 NGSOC（告警引擎）
           ↓ 告警
   钉钉 / 企微 / 电话 / 工单
```

### 1.3 告警规则

| 场景 | 规则 | 告警等级 |
| --- | --- | --- |
| 登录失败 ≥ 10 次/5min/同 IP | 暴力破解 | P1 |
| 同一用户多设备登录 | 账号共享 | P2 |
| 异常时段操作（如凌晨 3 点批量下载）| 异常行为 | P1 |
| 数据库慢查询 ≥ 100/min | 性能异常 | P2 |
| API 5xx ≥ 5%/1min | 服务异常 | P2 |
| 文件上传 ≥ 1GB/单用户/1hour | 大文件泄露 | P1 |
| 外发审批批量操作 | 合规风险 | P2 |

| --- | --- | --- |

## 二、终端 EDR（G-4）

### 2.1 选型

| 候选 | 平台 | 优势 | 劣势 | 推荐度 |
| --- | --- | --- | --- | --- |
| **方案 B 决策** | 不部署驱动 | 零 BSOD 风险 | 无终端文件级加密 | ⭐⭐⭐⭐ |
| **CrowdStrike Falcon** | Windows/Mac/Linux | 全球最佳 | 商业授权 80-150/终端/年 | ⭐⭐⭐⭐⭐ |
| **Microsoft Defender for Endpoint** | Windows | 与 Windows 集成 | 仅 Windows | ⭐⭐⭐⭐ |
| **Carbon Black** | 全平台 | 国内合规 | 商业授权 50-100/终端/年 | ⭐⭐⭐⭐ |
| **OSSEC + OSSEC-WUI** | 开源 | 免费 | 配置复杂 | ⭐⭐⭐ |

**推荐**：
- Windows：CrowdStrike Falcon（如预算允许）/ Microsoft Defender for Endpoint（已含在 M365 E5）
- macOS / Linux：CrowdStrike Falcon / OSSEC
- 移动端（iOS/Android）：MDM + Apple Business Manager / Android Enterprise

### 2.2 EDR 部署架构

```
EDAM 终端（Windows / mac / / / 移动）
       ↓ EDR Agent
EDR 管理平台（CrowdStrike Falcon 云）
       ↓ 事件流
EDAM SOC（v3.3 W-1 G-2）
       ↓ 告警
运维 / 安全团队
```

### 2.3 EDR 检测规则

| 场景 | 检测方式 |
| --- | --- |
| 异常进程启动 | 进程白名单对比 |
| 文件篡改 | 关键文件 hash 监控 |
| 横向移动 | SMB / RDP 异常 |
| 数据外泄 | 大文件外发检测 |
| 勒索软件 | 文件加密行为监控 |
| 凭据窃取 | LSASS 访问监控 |
| 越权访问 | 提权检测 |

### 2.4 终端管控补偿（方案 B 配套）

由于方案 B 决策移除终端驱动层，EDR 必须承担以下额外职责：

| 原驱动层职责 | EDR 替代方案 |
| --- | --- |
| 本地文件加密 | ❌ EDR 无法替代（必须靠应用层）|
| 剪贴板管控 | ⚠️ 应用层 JavaScript 拦截（方案 B §5.6.4）|
| 截屏检测 | ⚠️ 应用层 Canvas 高频水印（方案 B §5.6.5）|
| 打印管控 | ⚠️ 网络打印机 + 应用层打印确认 |
| 离线保护 | ❌ EDR 可检测离线，但无法阻止 |
| 心跳上报 | ✅ EDR Agent 持续心跳 |
| 驱动失效兜底 | ✅ EDR 告警 |

### 2.5 EDR + SOC 联动

- EDR Agent 检测到异常 → 推送到 SOC
- SOC 关联分析（终端 + 网络 + 应用）
- 自动响应：隔离终端、吊销 Token、禁用账户
- 人工介入：应急小组响应
