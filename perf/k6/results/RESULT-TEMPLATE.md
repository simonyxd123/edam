# k6 压测结果记录模板（v3.4 V4-03）

> 使用说明：
> 1. 复制本文件到 `perf/k6/results/{stage}-{date}.md`（如 `load-2026-09-08.md`）
> 2. 填入实际压测数据
> 3. 关联 JSON 输出文件
> 4. commit 到 git 作为发版前性能基线
