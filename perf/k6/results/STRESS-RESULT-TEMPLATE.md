# k6 极限测试结果记录模板（v3.4 V4-03 阶段 4）

> 使用说明：
1. 仅用于**极限档**（stress-test.js，1000 QPS × 5min）
2. 复制本文件到 `perf/k6/results/stress-{date}.md`
3. 填入实际压测数据
4. 关联 JSON 输出文件
5. commit 到 git 作为容量上限与瓶颈识别记录

---
