# k6 负载测试结果记录模板（v3.4 V4-03 阶段 2）

> 使用说明：
1. 仅用于**负载档**（load-test.js，200 QPS × 10min）
2. 复制本文件到 `perf/k6/results/load-{date}.md`
3. 填入实际压测数据
4. 关联 JSON 输出文件
5. commit 到 git 作为发版前性能基线
