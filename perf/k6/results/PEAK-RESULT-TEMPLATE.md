# k6 峰值测试结果记录模板（v3.4 V4-03 阶段 3）

> 使用说明：
1. 仅用于**峰值档**（peak-test.js，500 QPS × 10min）
2. 复制本文件到 `perf/k6/results/peak-{date}.md`
3. 填入实际压测数据
4. 关联 JSON 输出文件
5. commit 到 git 作为弹性与告警验证记录

---

| 项 | 值 |
| --- | --- |
