## 八、未达标时的应急方案

### 8.1 load 档未达标

| 严重度 | 行动 |
| --- | --- |
| P99 超 100ms | 优化 MySQL 索引 + 缓存预热，重跑 |
| 错误率 > 1% | 调大 DB 连接池 + 限流阈值 |

### 8.2 整体决策调整

如发现**严重问题**：

1. 立即停止发版流程
2. 在 `modify/2026-09-08-V4-03-容量基线报告-紧急.md` 追加问题分析
3. 召集架构组 + SRE + 后端 TL 紧急会议
4. 决策：紧急修复 vs 推迟发版 vs 回滚
